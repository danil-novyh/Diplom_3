# Diplom_3

UI Автотесты для Stellar Burgers

Автоматизированное тестирование веб-приложения [Stellar Burgers](https://stellarburgers.education-services.ru/) с использованием Selenium WebDriver и pytest.

Описание проекта

Проект содержит UI-тесты для проверки основной функциональности приложения Stellar Burgers, реализованные с использованием паттерна Page Object Model (POM).

Основная функциональность:
- Переход в раздел "Конструктор" через header
- Переход в раздел "Лента Заказов" через header
- Открытие модального окна с деталями ингредиента
- Закрытие модального окна кликом по крестику
- Увеличение счетчика ингредиента при добавлении в заказ

Лента заказов:
- Увеличение счетчика "Выполнено за все время" при создании заказа
- Увеличение счетчика "Выполнено за сегодня" при создании заказа
- Появление номера заказа в разделе "В работе"

Инструкция по запуску:

1. Создание виртуального окружения
python -m venv venv

2. Установка зависимостей
pip install -r requirements.txt
3. Запуск тестов
Запуск всех тестов в Chrome:
pytest --browser=chrome
Запуск всех тестов в Firefox:
pytest --browser=firefox
Запуск с генерацией Allure отчета:
pytest tests --alluredir=allure_results
Просмотр Allure отчета:
allure serve allure-results
